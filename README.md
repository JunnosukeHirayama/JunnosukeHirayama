## Projects
### [Forme（PDFフォーム作成・回答回収アプリ）](https://github.com/JunnosukeHirayama/Forme)
- **概要:** PDFに入力欄を配置し、共有URLから回答を受け取り、記入済みPDFやCSVとして回収できる Web アプリです。作成者はメールの確認コードでログインし、回答者はログインせずに回答できます。Next.js・TypeScript・Supabaseを用い、公開版と下書きの分離、編集競合の検出、重複送信防止、日本語PDF出力を実装しています。

### [ロウソクの炎の2次元数値解析](https://github.com/JunnosukeHirayama/CandleShapeAnalysis)
- **概要:** ロウソクの炎が形成する特徴的な「ティアドロップ型」の形状と、周囲の空気の対流（流速場）をシミュレーションするPythonプログラムです。外部の重い流体解析（CFD）ライブラリを使用せず、物理現象を支配する偏微分方程式をNumPyを用いた配列演算のみでスクラッチ実装しています。

### [SEO業務における記事内部リンクの管理効率化WEBアプリ](https://github.com/JunnosukeHirayama/GAS-app.1)
- **概要:** WEBメディアのSEO業務における記事の内部リンク管理を効率化するためのアプリです。具体的にはどの記事がどの記事へ内部リンクが繋がっているのかや、 記事ごとの保有リンクの数、SEOで重要になるトピッククラスターの管理を視覚的に分かりやすくし、内部リンク情報の追加削除も直感的に行えるようにするためのものです。

### [ビットコイン自動取引システム(GMO Coin API連携 自動取引ボット)](https://github.com/JunnosukeHirayama/BTC_Automated_Trading_System)
- **概要:** PythonとTkinterを用いて開発した、ビットコイン（BTC）の自動取引シミュレーターです。GMOコインのAPIからリアルタイムな板情報（Bid/Ask/LTP）を取得し、内部で計算したテクニカル指標（RSI、Z-Score、サポートライン）と組み合わせて自律的な売買判断を行います。 資産推移のリアルタイムグラフ描画や、Maker手数料（マイナス手数料）を考慮した損益計算ロジックを実装しています。
